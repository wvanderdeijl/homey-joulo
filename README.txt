Joulo integration for Homey

Monetize and monitor your EV charging sessions with Joulo (ERE / Emissiereductie-eenheden).

Features:
- Track cumulative energy and live charging power.
- Monitor accrued ERE credits and financial earnings.
- Automate Homey flows when charging sessions start or finish.
- Remotely restart chargers via Joulo's OCPP management gateway.
